Everything you need, nothing you don't

One small app for the databases your team uses every day.

Five databases

MySQL, MariaDB, PostgreSQL, SQL Server and SQLite in one place, with SSL and connect-by-URI.

SSH tunnel

SQL editor

Install in a minute

Dbro installs for your Windows user only and does not need administrator rights.

Download

Click “Download for Windows” above to get Dbro-Setup.exe, and check its SHA-256 if you like.

Run the installer

Choose the install folder and whether to add a desktop shortcut, then click Install.

Stay up to date

Dbro checks for updates when it starts (or Help › Check for Updates…). Your connections and scripts are kept.

If Windows shows “Windows protected your PC”, click More info → Run anyway. This appears because the installer is not code-signed yet; make sure you downloaded it from this page.

Your data stays on your computer

Dbro has no server and sends nothing to us. It only connects to the databases you choose, and to GitHub to check for updates.

Encrypted passwords

Saved passwords are encrypted with Windows (DPAPI) and can only be read by your Windows account, on your computer.

Verified connections

SSL checks the server certificate by default and SSH checks the host key, so nobody in between can pose as your server.

No open ports, no tracking

Dbro does not listen on the network and collects no usage data or analytics.

Tamper-protected app

The app checks its own files at start-up and refuses to run if they were modified.

Good habits: download Dbro only from this page · keep “Verify server certificate” on · if Dbro warns that an SSH host key changed, stop and ask your IT team · keep dump files private, they contain your data.
